# 2026 보령 꿀잼야행 · 황금 패랭이를 찾아라

보령 전통시장을 따라 진행하는 모바일 QR 미션투어입니다. 참가자는 망루, 한내시장 쉼터, 포목거리, 보부상 조형물을 이동하며 세 개의 징표를 모으고 황금 패랭이를 완성합니다.

## 주요 기능

- QR 주소별 미션 페이지와 순차 잠금
- 반사 글자 입력, 보령 3미 암호 입력, 황금송 미션
- 갓끈·동백꽃 장식·황금 인장 획득 화면
- 이동 지도 팝업
- 카메라 또는 사진 업로드 기반 황금 패랭이 인증사진 합성
- 네이버폼 만족도 조사 연결과 현장 경품 확인 화면
- 관리자용 설문 링크·혜택 설정

## 주요 주소

- `/golden` : 메인 서사 안내
- `/golden?mission=1` : 망루 미션
- `/golden?mission=2` : 보령 3미 미션
- `/golden?mission=3` : 보부상 조형물 미션
- `/golden?mission=4` : 최종 인증사진·만족도 조사
- `/admin` : 운영 설정

## 실행 환경

- Node.js 22.13 이상
- npm
- 카메라 기능은 HTTPS 또는 localhost에서만 정상적으로 동작합니다.

## 로컬 실행

```bash
npm ci
npm run dev
```

개발 서버가 표시한 주소를 브라우저에서 열어 확인합니다.

## 빌드

```bash
npm run build
```

현재 프로젝트는 Vinext와 Cloudflare Workers/D1 환경을 기준으로 구성되어 있습니다.

## 데이터베이스 설정

`DB` 이름의 Cloudflare D1 바인딩이 필요합니다. 최초 배포 시 `migrations/0000_init.sql`의 SQL을 실행해 테이블을 생성합니다.

관리자 기능을 사용하려면 배포 환경에 `ADMIN_PASSWORD`를 설정합니다. 실제 비밀번호는 GitHub에 커밋하지 마세요.

## 운영 설정

기본 만족도 조사 주소는 소스에 포함되어 있습니다. 관리자 페이지를 통한 설정값과 행사 응답 데이터는 D1 데이터베이스에 저장되므로 Git 저장소에는 포함되지 않습니다.

## GitHub 공개 전 주의사항

미션 정답이 클라이언트 코드에 포함되어 있습니다. 행사 진행 중 정답 노출을 막아야 한다면 저장소를 **Private**으로 생성하는 것을 권장합니다.
